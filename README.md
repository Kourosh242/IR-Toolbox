# IVA — جعبه ابزار آیوا 🧰

یک **وب‌اپ کاملاً محلی و آفلاین** با بیش از ۴۰ ابزار کاربردی (متن، توسعه، طراحی، فایل، محاسبات، زمان، امنیت، سرگرمی و بازی فکری) به‌همراه **گاوصندوق رمزنگاری IVA Vault**.

- 🔒 **بدون سرور، بدون دیتابیس، بدون آپلود** — همه‌چیز داخل مرورگر شماست.
- 🇷 **فارسی و راست‌چین** با فونت خودمیزبان وزیرمتن (بدون CDN، مناسب ایران).
- 📲 **PWA واقعی** — قابل نصب و قابل استفاده آفلاین.
- 🧩 **رجیستری ماژولار** — افزودن ابزار جدید بدون دست‌کاری هسته اپ.

---

## ۱) اجرا روی دستگاه خودتان

IVA فقط یک سایت استاتیک است؛ هر سرویس‌دهنده استاتیکی جواب می‌دهد:

```bash
# پایتون (ساده‌ترین راه)
cd iva
python3 -m http.server 8000
# سپس در مرورگر: http://localhost:8000
```

یا بدون هیچ سروری، `index.html` را باز کنید — ابزارها کار می‌کنند، فقط Service Worker و نصب PWA به `http(s)` نیاز دارند (روی `file://` به‌صورت خودکار غیرفعال می‌شوند).

## ۲) انتشار آنلاین (رایگان و در دسترس از ایران)

کل پوشه را به یک هاست استاتیک بسپرید؛ پیشنهاد اول **Codeberg Pages** و جایگزین **GitHub Pages** (هر دو از ایران در دسترس‌اند):

1. پوشه `iva` را به‌صورت یک ریپازیتوری آپلود کنید (محتوای همین پوشه = ریشه سایت).
2. در Codeberg: Settings → Pages → شاخه اصلی را فعال کنید.
3. در GitHub: Settings → Pages → شاخه `main` و پوشه root (یا Actions با یک static deploy).

نکته: مسیرها نسبی هستند و build step لازم نیست.

## ۳) نصب به‌صورت اپ (PWA)

- **دسکتاپ/اندروید (کرومیوم):** وقتی شرایط نصب فراهم باشد، دکمه «📲 نصب اپ» در خانه و تنظیمات ظاهر می‌شود؛ یا از منوی مرورگر «Install app».
- **iOS/iPadOS (سافاری):** دکمه Share ← «Add to Home Screen». (مرورگر اپل prompt سفارشی ندارد؛ IVA هم ادعایی ندارد و دقیقاً همین راهنما را نشان می‌دهد.)
- پس از نصب، IVA بدون اینترنت هم کامل کار می‌کند؛ Service Worker پوسته و فایل‌ها را از کش نسخه‌دار می‌خواند.

## ۴) گاوصندوق IVA و فایل ‎`.iva256`

### رمزنگاری
| مرحله | الگوریتم |
|---|---|
| مشتق کلید | PBKDF2-HMAC-SHA-256 با **۲۵۰٬۰۰ تکرار** و salt تصادفی ۱۶ بایتی |
| رمزنگاری | **AES-256-GCM** با IV تصادفی ۱۲ بایتی (احراز اصالت داخلی) |
| تصادفی‌ها | `crypto.getRandomValues` (CSPRNG مرورگر) |

رمز عبور و کلید **هرگز ذخیره نمی‌شوند**؛ فقط در حافظه حین عملیات. فراموشی رمز = غیرقابل بازیابی بودن داده (این یک ویژگی امنیتی است، نه باگ).

### قالب باینری `.iva256` (نسخه‌دار و خودتوصیف)
```
[4]  magic   "IVA1"
[1]  version = 1
[1]  kdfId   = 1  (PBKDF2-HMAC-SHA256/250k)
[1]  algId   = 1  (AES-256-GCM)
[2]  saltLen + salt
[2]  ivLen   + iv
[4]  ctLen   + ciphertext (شامل auth tag)
```
بخش رمزگشایی‌شده شامل متادیتای JSON (نام و MIME فایل‌ها برای بازیابی صحیح) و سپس بلوک‌های `[طول][بایت]` هر فایل است — یعنی چند فایل در یک کانتینر، بدون Base64 حجیم.

### رفتار خطا
رمز اشتباه یا فایل دستکاری‌شده → **یک پیام عمومی**: «بازگشایی ممکن نشد — رمز عبور اشتباه است یا فایل دستکاری شده.» (بدون لو دادن جزئیات به مهاجم).

> ⚠️ هش ≠ رمزنگاری. ابزار «بررسی هش» برای اثر انگشت داده است (SHA-256/384/512؛ SHA-1 فقط برای سازگاری و با هشدار ناامن بودن). برای محرمانگی از Vault استفاده کنید. هیچ ابزاری «شکست‌ناپذیر» ادعا نمی‌شود.

## ۵) افزودن ابزار جدید (بدون بازنویسی اپ)

یک فایل در `tools/` بسازید (یا به فایل دسته موجود اضافه کنید) و ثبت کنید:

```js
import { register } from '../js/registry.js';
register({
  id: 'my-tool',            // یکتا
  cat: 'text',              // یکی از دسته‌های registry.CATS
  icon: '✨',
  fa: 'ابزار من', en: 'My Tool',
  desc: 'توضیح یک‌خطی',
  keywords: ['my', 'tool'],
  mount(root) {             // ساخت رابط داخل root
    root.append(/* DOM */);
  },
});
```
سپس همان فایل را در `js/app.js` یک بار import کنید. جستجو، کارت‌ها، دسته‌بندی، علاقه‌مندی و پالت فرمان **خودکار** ابزار شما را می‌شناسند — هیچ داده ناوبری دیگری برای به‌روزرسانی نیست.

## ۶) Service Worker و نسخه کش

- `service-worker.js` با ثابت `VERSION = 'iva-v1'` کار می‌کند. با تغییر این مقدار، کش قدیمی در رویداد `activate` حذف و کش جدید ساخته می‌شود.
- استراتژی: ناوبری‌ها network-first با fallback به پوسته کش‌شده (آفلاین)، فایل‌های استاتیک cache-first با پر شدن تدریجی.
- **هیچ محتوای حساسی کش نمی‌شود**؛ خروجی‌های Vault فقط در حافظه‌اند.

## ۷) ذخیره‌سازی محلی

کلیدهای `localStorage` با پیشوند `iva:` — تنظیمات (پوسته/کاهش حرکت)، علاقه‌مندی‌ها، اخیراً استفاده‌شده‌ها (فقط شناسه ابزار، نه مقدار ورودی‌ها) و رکورد بازی‌ها. خروجی/ورودی `iva-settings.json` از تنظیمات امکان‌پذیر است و شامل رمز گاوصندوق نیست.

## ۸) سازگاری

مرورگرهای مدرن با پشتیبانی ES Modules + Web Crypto (کروم/اج ۸۰+، فایرفاکس ۷۵+، سافاری ۱۴+). روی `file://` هم ابزارها کار می‌کنند؛ SW/نصب فقط روی `http(s)`.

## ۹) ساختار پروژه

```
iva/
├─ index.html            پوسته RTL + لینک PWA
├─ manifest.json         متادیتای PWA (fa/rtl)
├─ service-worker.js     کش نسخه‌دار + آفلاین
├─ css/                  themes / main / components / responsive
├─ js/                   app, router, registry, storage, ui, search, pwa, …
├─ tools/                ماژول‌های ابزار (text, dev, design, files, math, time, security, fun, brain)
├─ vault/                crypto-utils, file-format, vault UI
├─ assets/               fonts (Vazirmatn), icons
├─ scripts/make-icons.mjs تولید آیکون‌های PNG بدون وابستگی
└─ e2e/                  تست‌های Playwright
```

## ۱۰) تغییرات ورژن

صفحه «🗂️ تغییرات ورژن» در منوی اپ (و فایل `js/changelog.js`) فهرست تغییرات/افزوده‌ها/حذف‌های هر نسخه را نگه می‌دارد؛ بعد از هر آپدیت یک مدخل جدید اضافه می‌شود.

## ۱۱) تست

```bash
npx playwright test   # نیازمند نصب playwright و مرورگرها
```
تست‌ها شامل: رندر خانه، فرمتر JSON، Base64 فارسی، تطبیق SHA-256، چرخه کامل Vault (رمز درست/غلط/دستکاری)، ماندگاری علاقه‌مندی و پوسته، پالت Ctrl+K، ثبت SW و عدم سرریز افقی موبایل.
