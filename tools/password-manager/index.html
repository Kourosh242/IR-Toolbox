🔑 مدیر رمز عبور

Password Manager

مدیر رمز عبور کاملاً محلی: ورودی‌ها با AES-256-GCM و رمز اصلی رمزنگاری و فقط روی دستگاه شما ذخیره می‌شوند.

باز کردن «مدیر رمز عبور» در IR-Toolbox

قابلیت‌ها

  • رمزنگاری AES-256-GCM با مشتق کلید PBKDF2-HMAC-SHA-256 (۶۰۰٬۰۰۰ تکرار)
  • رمز اصلی هرگز ذخیره نمی‌شود؛ بعد از هر بستن یا رفرش صفحه، گنجینه قفل است
  • جست‌وجو، ویرایش، حذف، تولید رمز امن و کپی موقت با پاک‌شدن کلیپ‌بورد پس از ۲۰ ثانیه
  • پشتیبان رمزنگاری‌شده و بازیابی آن، به‌همراه تغییر رمز اصلی (بازرمزنگاری کامل داده‌ها)
  • شمارش تکرار KDF همراه داده ذخیره می‌شود؛ گنجینه‌های قدیمی با ۲۵۰٬۰۰۰ تکرار همچنان باز می‌شوند
  • ورودی‌های پشتیبانِ دست‌کاری‌شده یا غیررشته‌ای پیش از رمزگشایی پاک‌سازی می‌شوند (sanitize)
  • خطای ذخیره باعث حذف ورودی موجود نمی‌شود (بازگردانی کامل)

راهنمای استفاده

مدیر رمز عبور کاملاً محلی: بار اول «رمز اصلی» می‌سازید؛ ورودی‌ها (عنوان، کاربر، رمز با هر زبان/فرمتی، آدرس، یادداشت) با AES-256-GCM رمزنگاری و فقط روی دستگاه شما ذخیره می‌شوند. جست‌وجو، ویرایش، حذف، تولید رمز امن، کپی موقت (پاک‌شدن کلیپ‌بورد بعد از ۲۰ ثانیه) و پشتیبان رمزنگاری‌شده. فراموشی رمز اصلی = از دست رفتن داده؛ ویژگی امنیتی است.

حریم خصوصی این ابزار

ورودی‌ها با AES-256-GCM رمزنگاری می‌شوند و کلید با PBKDF2 (۶۰۰٬۰۰۰ تکرار) از رمز اصلی مشتق می‌شود. رمز اصلی هرگز ذخیره نمی‌شود و پس از هر بستن یا رفرش صفحه، گنجینه قفل است. داده‌ها فقط در localStorage همین مرورگر می‌مانند و هیچ‌جا ارسال نمی‌شوند. رمزنگاری نیازمند محیط امن (HTTPS یا localhost) است.

پرسش‌های پرتکرار

اگر رمز اصلی را فراموش کنم چه؟

داده‌ها قابل بازیابی نیستند. این یک ویژگی امنیتی است، نه باگ: بدون کلید، هیچ راه برگشتی وجود ندارد. پشتیبان رمزنگاری‌شده هم بدون رمز اصلی بی‌استفاده است.

چرا در بعضی محیط‌ها ابزار کار نمی‌کند؟

Web Crypto فقط در محیط امن (HTTPS یا localhost) در دسترس است. روی file:// یا http معمولی، مرورگر اجازهٔ رمزنگاری نمی‌دهد و ابزار هشدار واضح نشان می‌دهد.
