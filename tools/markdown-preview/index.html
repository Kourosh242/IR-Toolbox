Ⓜ️ پیش‌نمایش Markdown

Markdown Preview

متن Markdown را به‌صورت محلی و امن رندر می‌کند — تیتر، متن ضخیم و کج، کد، نقل‌قول، لیست و لینک.

باز کردن «پیش‌نمایش Markdown» در IR-Toolbox

قابلیت‌ها

  • کل متن ابتدا escape می‌شود، سپس نشانه‌گذاری اعمال می‌شود؛ پس کد مخرب اجرا نمی‌شود
  • لینک‌ها فقط با http/https ساخته می‌شوند و rel="noopener" می‌گیرند
  • پشتیبانی از تیترهای سطح ۱ تا ۶، لیست، نقل‌قول و کد درون‌خطی

راهنمای استفاده

متن Markdown بنویسید و رندر امن آن را همان لحظه ببینید (تیتر، بولد، لیست، نقل‌قول، لینک). خروجی escape می‌شود تا کد مخرب اجرا نشود.

حریم خصوصی این ابزار

این ابزار کاملاً داخل مرورگر اجرا می‌شود. ورودی شما به هیچ سروری ارسال نمی‌شود و هیچ درخواست شبکه‌ای برای پردازش آن انجام نمی‌گیرد.

پرسش‌های پرتکرار

آیا می‌توانم HTML خام داخل Markdown بگذارم؟

خیر؛ عمداً escape می‌شود تا اجرای اسکریپت ممکن نباشد. این یک تصمیم امنیتی است، نه کمبود.

پشتیبانی از جدول و تصویر هم دارد؟

در حال حاضر جدول و تصویر پشتیبانی نمی‌شوند؛ تمرکز روی عناصر پرکاربرد و امن است.
