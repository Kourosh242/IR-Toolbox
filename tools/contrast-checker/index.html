🌓 بررسی کنتراست

Contrast Checker (WCAG)

نسبت کنتراست رنگ متن و پس‌زمینه را بر اساس WCAG محاسبه می‌کند و قبولی AA و AAA را برای متن معمولی و بزرگ نشان می‌دهد.

باز کردن «بررسی کنتراست» در IR-Toolbox

قابلیت‌ها

  • محاسبهٔ روشنایی نسبی مطابق فرمول WCAG و نسبت کنتراست دقیق
  • سه بررسی هم‌زمان: AA متن معمولی (۴.۵)، AA متن بزرگ (۳) و AAA (۷)
  • پیش‌نمایش زندهٔ متن روی رنگ انتخابی

راهنمای استفاده

دو رنگ متن و پس‌زمینه را انتخاب کنید؛ نسبت کنتراست و قبولی معیارهای WCAG (AA متن معمولی/بزرگ و AAA) با ✔/✘ نمایش داده می‌شود. برای طراحی accessibile.

حریم خصوصی این ابزار

این ابزار کاملاً داخل مرورگر اجرا می‌شود. ورودی شما به هیچ سروری ارسال نمی‌شود و هیچ درخواست شبکه‌ای برای پردازش آن انجام نمی‌گیرد.

پرسش‌های پرتکرار

مبنای محاسبه چیست؟

روشنایی نسبی هر رنگ با ضرایب ۰.۲۱۲۶/۰.۷۱۵۲/۰.۰۷۲۲ و گامای ۲.۴ محاسبه می‌شود، سپس نسبت (L1+0.05)/(L2+0.05).

کدام آستانه را رعایت کنم؟

برای متن معمولی حداقل ۴.۵:۱ (AA) و برای متن بزرگ حداقل ۳:۱. AAA (۷:۱) برای خوانایی بهتر توصیه می‌شود.
