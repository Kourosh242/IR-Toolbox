۵۲ ابزار مرورگری در ۹ دسته

همهٔ ابزارهای IR-Toolbox، دسته‌بندی‌شده. هر ابزار کاملاً در مرورگر اجرا می‌شود و بعد از اولین بارگذاری، آفلاین کار می‌کند.

باز کردن اپ IR-Toolbox · دربارهٔ پروژه و حریم خصوصی

ابزارهای متن (۵)

شمارش، تبدیل و پاک‌سازی متن فارسی و انگلیسی — مستقیم داخل مرورگر. هیچ متنی به سروری فرستاده نمی‌شود؛ حتی متن‌های بلند هم فقط در حافظهٔ همان تب پردازش می‌شوند.

  • 🔢 شمارنده متن
  • 🔠 تبدیل حروف
  • 🧹 پاک‌سازی متن
  • 🔁 جستجو و جایگزینی
  • 📜 لورم فارسی

ابزارهای توسعه‌دهنده (۱۲)

ابزارهای روزمرهٔ برنامه‌نویسان: JSON، Base64، URL، اسلاگ، UUID، JWT، Regex، Timestamp، مترجم Cron و QR‌کدساز/QR‌خوان. همه آفلاین و بدون ارسال کد یا توکن به هیچ سرویس بیرونی.

  • 🧾 فرمت‌کننده JSON
  • 📦 Base64
  • 🔗 کدگذاری URL
  • 🐌 اسلاگ‌ساز
  • 🪪 تولیدکننده UUID
  • 🎫 رمزگشای JWT
  • 🧲 آزمایش Regex
  • 🏷️ HTML Entities
  • 🕰️ تبدیل Timestamp
  • 🔳 QR‌کدساز
  • 📷 QR‌خوان
  • ⏰ مترجم Cron

ابزارهای طراحی (۵)

رنگ، کنتراست WCAG، گرادیان، سایه و تایپوگرافی — با خروجی CSS آمادهٔ کپی و پیش‌نمایش زنده، برای طراحان و توسعه‌دهندگان فرانت‌اند.

  • 🎨 تبدیل رنگ
  • 🌓 بررسی کنتراست
  • 🌈 گرادیان‌ساز CSS
  • 🌫️ سایه‌ساز CSS
  • 📏 تبدیل px ↔ rem

ابزارهای فایل (۵)

اطلاعات فایل، تبدیل تصویر به Base64 و برعکس، پیش‌نمایش Markdown و تبدیل CSV ↔ JSON. فایل‌ها فقط در حافظهٔ مرورگر خوانده می‌شوند و هرگز آپلود نمی‌شوند.

  • 📄 اطلاعات فایل
  • 🖼️ تصویر به Base64
  • 📥 Base64 به فایل
  • Ⓜ️ پیش‌نمایش Markdown
  • 🧺 CSV ↔ JSON

ابزارهای محاسبات (۶)

ماشین‌حساب علمی با ارزیابی امن، درصد، تبدیل واحد، BMI، عدد تصادفی رمزنگاری‌شده و جداکنندهٔ هزارگان — با پشتیبانی از ارقام فارسی.

  • 🧮 ماشین‌حساب علمی
  • ٪ ماشین‌حساب درصد
  • ⚖️ تبدیل واحد
  • 🫀 شاخص توده بدنی
  • 🎲 عدد تصادفی
  • 🧾 جداکنندهٔ ۳ رقمی

ابزارهای زمان و تقویم شمسی (۶)

تبدیل تاریخ جلالی (شمسی) و میلادی، محاسبهٔ سن، اختلاف دو تاریخ، کرنومتر، تایمر شمارش معکوس و پومودورو — با پیکر تاریخ شمسی و نام ماه‌های فارسی.

  • 📅 تبدیل تاریخ شمسی ↔ میلادی
  • 🎂 محاسبه سن
  • ⏳ اختلاف دو تاریخ
  • ⏱️ کرنومتر
  • ⏲️ تایمر شمارش معکوس
  • 🍅 پومودورو

ابزارهای امنیت (۵)

هش SHA-256/384/512 و SHA-1، تولید رمز عبور و توکن امن با مولد رمزنگاری مرورگر، مدیر رمز عبور رمزنگاری‌شده و گاوصندوق IR با AES-256-GCM. کلیدها هرگز ذخیره یا ارسال نمی‌شوند.

  • #️⃣ بررسی هش
  • 🔑 تولید رمز عبور
  • 🧬 توکن امن
  • 🔑 مدیر رمز عبور
  • 🧰 گاوصندوق IR

ابزارهای سرگرمی (۵)

جوک، ایده، سوالات یخ‌شکن، ایموجی و شیر‌یا‌خط/تاس — با محتوای داخلی و کاملاً آفلاین؛ بدون هیچ درخواست شبکه‌ای.

  • 😄 جوک‌سرا
  • 💡 ایده‌پرداز
  • 🗣️ سوالات دورهمی
  • \u{1F3AD} ایموجی تصادفی
  • 🪙 شیر یا خط + تاس

بازی‌های فکری (۳)

بازی حافظه، سرعت واکنش و ریاضی سرعتی با ثبت رکورد محلی روی همین دستگاه — بدون حساب کاربری و بدون ارسال امتیاز.

  • 🧠 بازی حافظه
  • ⚡ سرعت واکنش
  • ⏱️ ریاضی سرعتی

IR-Toolbox چند ابزار دارد؟

۵۲ ابزار در ۹ دسته: ابزارهای متن، ابزارهای توسعه‌دهنده، ابزارهای طراحی، ابزارهای فایل، ابزارهای محاسبات، ابزارهای زمان و تقویم شمسی، ابزارهای امنیت، ابزارهای سرگرمی، بازی‌های فکری.

آیا ابزارها بدون اینترنت کار می‌کنند؟

بله. بعد از اولین بارگذاری، همه‌چیز از کش Service Worker خوانده می‌شود و پردازش داده همیشه در مرورگر انجام می‌شود.

آیا ابزارها رایگان‌اند؟

بله؛ پروژه متن‌باز با لایسنس MIT است و هیچ پرداختی ندارد.
