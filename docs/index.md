# IVA — ویکی پروژه

> جعبه ابزار آیوا: یک **وب‌اپ کاملاً محلی و آفلاین** با ۴۵ ابزار کاربردی در ۹ دسته، به‌همراه **گاوصندوق رمزنگاری IVA Vault**.

این ویکی مرجع فنی و کاربری پروژه **IVA — جعبه ابزار آیوا** است. همه‌چیز داخل مرورگر شما اجرا می‌شود؛ هیچ سرور، دیتابیس یا ارسالی به اینترنت وجود ندارد.

## 🧰 نگاهی کلی به امکانات

- 🔒 **کاملاً محلی و آفلاین** — بدون سرور، بدون دیتابیس، بدون آپلود؛ داده‌های شما از دستگاه شما بیرون نمی‌رود.
- 🇮🇷 **فارسی و راست‌چین** — با فونت خودمیزبان وزیرمتن (بدون CDN، مناسب ایران).
- 📲 **PWA واقعی** — قابل نصب و استفاده‌ی کاملاً آفلاین.
- 🧩 **رجیستری ماژولار** — افزودن ابزار جدید بدون دست‌کاری هسته اپ.
- 🛡️ **گاوصندوق رمزنگاری** — AES-256-GCM با مشتق کلید PBKDF2.
- 🎨 **پوسته‌های متنوع** — روشن، تاریک، سیستم، نیمه‌شب و شیشه‌ای.
- ⌨️ **پالت فرمان** — جستجوی ابزار با `Ctrl+K` / `Cmd+K`.
