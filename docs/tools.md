# فهرست ابزارها

IVA شامل **۴۵ ابزار** در **۹ دسته** است. همه ابزارها در داخل مرورگر اجرا می‌شوند و هیچ‌کدام به سرور متصل نیستند.

## 📝 متن (۴ ابزار)

| ابزار | توضیح |
|---|---|
| شمارنده متن | کاراکتر، کلمه، جمله، خط، حجم UTF-8 و زمان مطالعه |
| تبدیل حروف | UPPER / lower / Title / معکوس |
| پاک‌سازی متن | حذف فاصله و خط خالی، تکراری، مرتب‌سازی |
| جستجو و جایگزینی | جایگزینی با شمارش تعداد موارد |

## 💻 توسعه‌دهنده (۹ ابزار)

| ابزار | توضیح |
|---|---|
| فرمت‌کننده JSON | زیباسازی، فشرده‌سازی و اعتبارسنجی با نمایش خطای دقیق |
| Base64 | کدگذاری/رمزگشایی با پشتیبانی UTF-8 (فارسی) |
| کدگذاری URL | `encodeURIComponent` و برعکس |
| اسلاگ‌ساز | تبدیل عنوان فارسی/انگلیسی به slug خوانا |
| تولیدکننده UUID | UUID v4 با `crypto.getRandomValues` |
| رمزگشای JWT | نمایش header و payload — بدون بررسی امضا |
| آزمایش Regex | تست الگو روی متن با هایلایت نتیجه |
| HTML Entities | Escape / Unescape کاراکترهای `< > & " '` |
| تبدیل Timestamp | unix ↔ میلادی و شمسی |

## 🎨 طراحی (۵ ابزار)

| ابزار | توضیح |
|---|---|
| تبدیل رنگ | HEX ↔ RGB ↔ HSL با پیش‌نمایش زنده |
| بررسی کنتراست | نسبت کنتراست و معیارهای WCAG AA/AAA |
| گرادیان‌ساز CSS | دو رنگ + زاویه → کد CSS آماده |
| سایه‌ساز CSS | تنظیم `box-shadow` با اسلایدرها |
| تبدیل px ↔ rem | با پایه‌ی قابل تغییر |

## 📁 فایل (۵ ابزار)

| ابزار | توضیح |
|---|---|
| اطلاعات فایل | نام، حجم، نوع و تاریخ تغییر — فقط در حافظه |
| تصویر به Base64 | ساخت Data URL برای جاسازی در HTML/CSS |
| Base64 به فایل | پیش‌نمایش زنده + دانلود |
| پیش‌نمایش Markdown | رندر محلی با خروجی امن (escape شده) |
| CSV ↔ JSON | تبدیل دوطرفه با تشخیص سرستون |

## 🧮 محاسبات (۵ ابزار)

| ابزار | توضیح |
|---|---|
| ماشین‌حساب علمی | با sqrt، sin، pow و… — ارزیابی امن |
| ماشین‌حساب درصد | درصد، افزایش/کاهش و تغییر درصدی |
| تبدیل واحد | طول، وزن، داده و دما |
| شاخص توده بدنی | BMI + دسته‌بندی WHO |
| عدد تصادفی | بازه دلخواه با مولد امن `crypto` |

## ⏰ زمان (۵ ابزار)

| ابزار | توضیح |
|---|---|
| تبدیل تاریخ شمسی ↔ میلادی | پیکر جلالی + روز هفته |
| محاسبه سن | ورودی شمسی یا میلادی، سن دقیق سال/ماه/روز |
| اختلاف دو تاریخ | روز، هفته و ماه تقریبی |
| کرنومتر | با ثبت دور (lap) |
| تایمر شمارش معکوس | با هشدار صوتی و لرزشی |

## 🔐 امنیت (۴ ابزار)

| ابزار | توضیح |
|---|---|
| بررسی هش | هش متن/فایل + تطبیق + شناسایی الگوریتم |
| تولید رمز عبور | با `crypto` + نشانگر قدرت/آنتروپی |
| توکن امن | Hex / Base64 با `crypto.getRandomValues` |
| گاوصندوق IVA | رمزنگاری متن/فایل با AES-256-GCM → `.iva256` |

## 🎉 سرگرمی (۵ ابزار)

| ابزار | توضیح |
|---|---|
| جوک‌سرا | بیش از ۹۰ جوک آفلاین فارسی |
| ایده‌پرداز | حدود ۱۰۰ ایده پروژه و کار |
| سوالات دورهمی | ۱۰۰ یخ‌شکن |
| ایموجی تصادفی | بیش از ۱۳۰ ایموجی |
| شیر یا خط + تاس | تصمیم‌گیر تصادفی |

## 🧠 بازی فکری (۳ ابزار)

| ابزار | توضیح |
|---|---|
| بازی حافظه | جفت‌یابی ایموجی — رکورد کمترین حرکت |
| سرعت واکنش | روی سبز کلیک کن — رکورد میلی‌ثانیه |
| ریاضی سرعتی | ۳۰ ثانیه، بیشترین جواب درست |

---

> **یادداشت امنیتی:** ابزار «بررسی هش» برای اثر انگشت داده است، نه رمزنگاری. برای محرمانگی از **گاوصندوق IVA** استفاده کنید. هیچ ابزاری «شکست‌ناپذیر» ادعا نمی‌شود.
