# PWA و حالت آفلاین

IR-Toolbox یک **PWA واقعی** است: قابل نصب به‌صورت اپ و استفاده‌ی کاملاً آفلاین.

## Service Worker

فایل `service-worker.js` با یک ثابت نسخه‌دار کار می‌کند:

```js
const VERSION = 'ir-v3';
```

- هنگام تغییر این مقدار، کش قدیمی در رویداد `activate` حذف و کش جدید ساخته می‌شود.
- **استراتژی:**
  - **ناوبری:** network-first با fallback به پوسته کش‌شده (برای آفلاین).
  - **فایل‌های استاتیک:** cache-first با پر شدن تدریجی.
- **هیچ محتوای حساسی کش نمی‌شود**؛ خروجی‌های گاوصندوق فقط در حافظه‌اند.

> نسخه `ir-v1` کش اولیه (CORE) را به‌همراه **همه ماژول‌های جاوااسکریپت** ثبت می‌کند (ابزارها، گاوصندوق، changelog و…) تا در **نصب اولیه و آفلاین** هم اپ بدون خطا کار کند.

## کش اولیه (CORE)

در رویداد `install` این فایل‌ها از پیش کش می‌شوند: پوسته، فایل‌های CSS، همه ماژول‌های JS، فونت وزیرمتن و آیکون‌ها. فایل‌های JS دیگر (ابزارها و گاوصندوق) هم که در زمان اجرا import می‌شوند در CORE ثبت شده‌اند تا آفلاین‌بودن کامل تضمین شود.

## نصب

- **دسکتاپ / اندروید (کرومیوم):** دکمه «📲 نصب اپ» در خانه و تنظیمات ظاهر می‌شود؛ یا Install app از منوی مرورگر.
- **iOS / iPadOS (سافاری):** Share ← Add to Home Screen. مرورگر اپل prompt سفارشی ندارد و IR-Toolbox دقیقاً همین راهنما را نشان می‌دهد.
- بعد از نصب، اپ مثل یک اپلیکیشن مستقل باز می‌شود.

## تشخیص وضعیت نصب

ماژول `js/pwa.js` وضعیت واقعی نصب را مدیریت می‌کند:

- `canInstall()` — آیا prompt نصب در دسترس است.
- `promptInstall()` — درخواست نصب واقعی.
- `isIOS()` / `isStandalone()` — تشخیص iOS و حالت مستقل.

همه این‌ها بر اساس قابلیت واقعی مرورگر است؛ هیچ شبیه‌سازی یا راهنمای دروغینی ارائه نمی‌شود.
