# ذخیره‌سازی محلی

IVA فقط داده‌هایی را محلی (در `localStorage`) ذخیره می‌کند که برای تجربه کاربر لازم باشند — **هیچ مقدار ورودی و هیچ رمز عبوری ذخیره نمی‌شود**.

## کلیدها

همه کلیدها با پیشوند `iva:` ذخیره می‌شوند:

| کلید | محتوا |
|---|---|
| `iva:settings` | پوسته (theme) و حالت کاهش حرکت (motion) |
| `iva:favs` | فهرست شناسه ابزارهای علاقه‌مندی |
| `iva:recents` | ابزارهای اخیراً استفاده‌شده (شناسه ابزار + timestamp) |
| `iva:scores` | رکوردهای بازی‌های فکری |

> `recents` فقط **شناسه ابزار** را نگه می‌دارد، نه مقدار ورودی‌ها.

## خروجی / ورودی تنظیمات

در صفحه تنظیمات می‌توانید فایل `iva-settings.json` را خروجی بگیرید یا وارد کنید:

```json
{
  "app": "iva-toolbox",
  "version": 1,
  "exportedAt": "…",
  "settings": { "theme": "light", "motion": "auto" },
  "favorites": [ … ],
  "recents": [ … ],
  "scores": { … }
}
```

- **این فایل شامل رمز گاوصندوق نیست** (رمز اصلاً ذخیره نمی‌شود).
- هنگام ورود، فایل با بررسی فیلد `app === "iva-toolbox"` اعتبارسنجی می‌شود.

## پاک‌سازی

دکمه «پاک‌سازی» همه کلیدهای `iva:*` را حذف می‌کند.

## چرا هیچ داده‌ای به سرور نمی‌رود؟

معماری IVA کاملاً client-side است: هیچ درخواست شبکه‌ای به جز خود فایل‌های استاتیک اپ ارسال نمی‌شود. بدون آنالیتیکس، بدون آپلود، بدون کوکی ردیابی.
