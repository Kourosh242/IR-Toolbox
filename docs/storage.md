# ذخیره‌سازی محلی

IR-Toolbox فقط داده‌هایی را محلی (در `localStorage`) ذخیره می‌کند که برای تجربه کاربر لازم باشند — **هیچ مقدار ورودی و هیچ رمز عبوری ذخیره نمی‌شود**.

## کلیدها

همه کلیدها با پیشوند `ir:` ذخیره می‌شوند:

| کلید | محتوا |
|---|---|
| `ir:settings` | پوسته (theme) و حالت کاهش حرکت (motion) |
| `ir:favs` | فهرست شناسه ابزارهای علاقه‌مندی |
| `ir:recents` | ابزارهای اخیراً استفاده‌شده (شناسه ابزار + timestamp) |
| `ir:scores` | رکوردهای بازی‌های فکری |
| `ir:passman` | داده‌های رمزنگاری‌شده مدیر رمز عبور |
| `ir:pomo` | رکورد روزانه پومودورو |

> `recents` فقط **شناسه ابزار** را نگه می‌دارد، نه مقدار ورودی‌ها.

## خروجی / ورودی تنظیمات

در صفحه تنظیمات می‌توانید فایل `ir-settings.json` را خروجی بگیرید یا وارد کنید:

```json
{
  "app": "ir-toolbox",
  "version": 1,
  "exportedAt": "…",
  "settings": { "theme": "light", "motion": "auto" },
  "favorites": [ … ],
  "recents": [ … ],
  "scores": { … }
}
```

- **این فایل شامل رمز گاوصندوق نیست** (رمز اصلاً ذخیره نمی‌شود).
- هنگام ورود، فایل با بررسی فیلد `app === "ir-toolbox"` اعتبارسنجی می‌شود.

## پاک‌سازی

دکمه «پاک‌سازی» همه کلیدهای `ir:*` را حذف می‌کند.

> **مهاجرت از نسخه‌های قدیمی (IVA):** کلیدهای قدیمی با پیشوند `iva:` در نخستین اجرا به‌صورت خودکار به پیشوند `ir:` منتقل و سپس حذف می‌شوند؛ تنظیمات، علاقه‌مندی‌ها و رکوردها حفظ می‌شوند. فایل‌های خروجی تنظیمات قدیمی با `app: "iva-toolbox"` هم هنگام ورود پذیرفته می‌شوند.

## چرا هیچ داده‌ای به سرور نمی‌رود؟

معماری IR-Toolbox کاملاً client-side است: هیچ درخواست شبکه‌ای به جز خود فایل‌های استاتیک اپ ارسال نمی‌شود. بدون آنالیتیکس، بدون آپلود، بدون کوکی ردیابی.
