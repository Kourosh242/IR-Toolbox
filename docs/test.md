# تست و کنترل کیفیت

پروژه شامل تست‌های **Playwright** برای صحت‌سنجی عملکرد اصلی است.

## اجرای تست‌ها

```bash
# نصب Playwright (یک‌بار)
npm i -D @playwright/test
npx playwright install chromium

# اجرای تست‌ها
npx playwright test
```

پیکربندی در `playwright.config.js` تعریف شده است: سرور تست با `python3 -m http.server 8090` روی `127.0.0.1` بالا می‌آید و تست‌ها روی همان اجرا می‌شوند.

> **اگر CDN مرورگرهای Playwright در دسترس نبود:** می‌توانید از Chromium بسته‌ی npm استفاده کنید:
>
> ```bash
> npm i -D @sparticuz/chromium
> node -e "require('@sparticuz/chromium').executablePath()"   # استخراج باینری و کتابخانه‌ها
> LD_LIBRARY_PATH=/tmp/al2023/lib E2E_SYSTEM_CHROMIUM=1 npx playwright test
> ```

## پوشش تست

تست‌ها در `e2e/ir.spec.js` قرار دارند و شامل:

- **رندر خانه** — نمایش داشبورد، ۹ دسته و بیش از ۴۰ ابزار.
- **فرمت‌کننده JSON** — زیباسازی و اعتبارسنجی با نمایش خطای دقیق.
- **Base64** — رفت‌وبرگشت متن فارسی.
- **ماشین‌حساب** — خروجی با جداکننده هزارگان فارسی.
- **SHA-256** — تطبیق هش.
- **چرخه کامل گاوصندوق** — رمز درست، رمز غلط و فایل دستکاری‌شده.
- **سازگاری رو به عقب گاوصندوق** — کانتینر قدیمی با magic «IVA1» و پسوند `.iva256` همچنان بازگشایی می‌شود.
- **علاقه‌مندی و پوسته** — ماندگاری در localStorage.
- **پالت Ctrl+K** — باز شدن و جستجو.
- **ثبت Service Worker** — در محیط `http(s)`.
- **عدم سرریز افقی موبایل** — در viewport موبایل.

## افزودن تست

برای هر ابزار/رفتار جدید، یک `test()` در `e2e/ir.spec.js` اضافه کنید که روی مسیر هش مربوطه (`/#/t/{id}`) ناوبری کند و خروجی انتظاری را بررسی کند.

## کنترل کیفیت دستی

قبل از انتشار، این موارد را بررسی کنید:

1. اپ روی `http://localhost:8000` بدون خطای کنسول باز می‌شود.
2. هر ابزار با پاک‌کردن ورودی، خروجی را پاک می‌کند.
3. گاوصندوق: رمزنگاری/بازگشایی/رمز غلط/فایل دستکاری.
4. آفلاین: بعد از یک بار بازدید، با قطع اینترنت همه ابزارها کار می‌کنند.
5. نصب PWA و پوسته‌ها درست کار می‌کنند.
