# شروع به کار

## ۱) اجرای روی دستگاه خودتان

IVA فقط یک **سایت استاتیک** است؛ هر سرویس‌دهنده استاتیکی آن را اجرا می‌کند. ساده‌ترین راه:

```bash
cd iva
python3 -m http.server 8000
# سپس در مرورگر: http://localhost:8000
```

یا بدون هیچ سروری، `index.html` را مستقیم در مرورگر باز کنید (دابل‌کلیک). ابزارها کار می‌کنند؛ فقط **Service Worker** و **نصب PWA** به پروتکل `http(s)` نیاز دارند و روی `file://` به‌صورت خودکار غیرفعال می‌شوند.

> مسیرها همه نسبی هستند و **نیازی به build نیست**.

## ۲) انتشار آنلاین (رایگان)

نسخه آنلاین از قبل روی **GitHub Pages** مستقر است:

```
https://kourosh242.github.io/IVA-Toolbox/
```

برای استقرار روی هاست استاتیک دلخواه کافی است کل پوشه پروژه را به‌عنوان ریشه سایت بسپارید.

### GitHub Pages

1. محتوای همین پوشه را به‌عنوان ریشه یک ریپازیتوری آپلود کنید.
2. در ریپازیتوری: **Settings → Pages** → شاخه `main` و پوشه root را انتخاب کنید.

### Codeberg Pages

1. محتوای پوشه را به‌صورت یک ریپازیتوری آپلود کنید.
2. در Codeberg: **Settings → Pages** → شاخه اصلی را فعال کنید.

## ۳) نصب به‌صورت اپ (PWA)

- **دسکتاپ / اندروید (کرومیوم):** وقتی شرایط نصب فراهم باشد، دکمه «📲 نصب اپ» در خانه و تنظیمات ظاهر می‌شود؛ یا از منوی مرورگر **Install app**.
- **iOS / iPadOS (سافاری):** دکمه **Share ← Add to Home Screen**. مرورگر اپل prompt سفارشی ندارد و IVA دقیقاً همین راهنما را نشان می‌دهد.
- پس از نصب، IVA **بدون اینترنت هم کاملاً کار می‌کند**؛ Service Worker پوسته و فایل‌ها را از کش نسخه‌دار می‌خواند.

جزئیات بیشتر در صفحه [PWA و آفلاین](pwa.md).

## ۴) سازگاری مرورگرها

مرورگرهای مدرن با پشتیبانی از **ES Modules** و **Web Crypto**:

- کروم / اج ۸۰+
- فایرفاکس ۷۵+
- سافاری ۱۴+

روی `file://` ابزارها کار می‌کنند؛ SW و نصب فقط روی `http(s)` فعال‌اند.
